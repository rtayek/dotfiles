# Project Browser Prototype Outcome

A project workspace is represented by a persistent browser tab group, independent of browser windows and monitors.

Each project may contain a self-contained `project-home.html`. That page defines the project's current web resources and helps create or rebuild its browser group. The browser owns group persistence and window placement.

The prototype demonstrated that this approach works without requiring a shell launcher, separate URL configuration, or browser extension. Additional automation can be considered later if rebuilding groups manually becomes burdensome.

Current links and presentation details belong only in `project-home.html`; they should not be duplicated here.
